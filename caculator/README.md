# מערכת מיצוי זכויות ונזקי גוף — בן לולו סיבוני · משרד עורכי דין

מערכת עצמאית מלאה (Standalone Web Application) בטכנולוגיית **Vanilla HTML5 / CSS3 / JavaScript** ללא שום תלות בוורדפרס או בספריות כבדות. 
מותאמת במדויק לשפה העיצובית, הטוקנים, הלוגו והמיתוג של **משרד עורכי דין בן לולו סיבוני** ([blslaw.co.il](https://www.blslaw.co.il/)).

---

## 📁 מבנה הקבצים בתיקייה (`bls-rights-system/`)

* **`index.html`**: עמוד השאלון הראשי — שאלון זכויות רספונסיבי בעברית מלאה (RTL), כפתור וואטסאפ צף, חיוג ישיר ומחשבון זכויות אינטראקטיבי.
* **`styles.css`**: מערכת עיצוב יוקרתית (Deep Espresso `#241710`, Warm Cream `#fbf5e8`, Metallic Gold `#d2a249`), טיפוגרפיית Heebo + Open Sans, ו-100% תאימות CSS Logical Properties.
* **`data.js`**: מילון נתונים מלא בעברית, שאלות השאלון, עילות תביעה ייחודיות (כולל **נפגעי איבה ומשרד הביטחון**), ומנוע חישוב זכויות חכם (`evaluateRights`).
* **`app.js`**: מנהל מצב האפליקציה, ולידציה ישראלית, לכידת לידים מיידית (כבר בשלב הזנת הטלפון והשם כדי לא לאבד נטישות מוקדמות), ותמיכה בוובהוק (Webhook).
* **`bhvuk.html`**: דשבורד ניהול ו-CRM מאובטח בסיסמה לצפייה בכל הפניות, ניהול סטטוסים, הערות וייצוא לאקסל.
* **`bhvuk.css`**: עיצוב יוקרתי ייעודי לדשבורד הניהול.
* **`bhvuk.js`**: מנוע ה-CRM — סינון, חיפוש מהיר, שינוי סטטוסי טיפול, שמירת הערות, סנכרון חי וייצוא CSV.
* **`logo.png`**: לוגו המדליון המוזהב של משרד בן לולו סיבוני.

## 🚀 אפשרויות העלאה והטמעה באתר הבנוי בקוד

מאחר שהמערכת בנויה כולה כקוד סטטי נקי, יש 3 דרכים פשוטות לחבר אותה:

### אפשרות 1: העלאה כתיקייה פנימית באתר הקיים (מומלץ)
פשוט מעתיקים את כל תכולת התיקייה `bls-rights-system` לתוך תיקייה באתר שלכם, למשל תחת הנתיב `/rights/` או `/calculator/`:
* כתובת השאלון תהיה: `https://www.blslaw.co.il/calculator/`
* כתובת דשבורד הניהול תהיה: `https://www.blslaw.co.il/calculator/bhvuk.html`

### אפשרות 2: הטמעה בתוך עמוד קיים באתר באמצעות `iframe`
אם תרצו שהשאלון יופיע בתוך עמוד שכבר קיים בעיצוב שלכם:
```html
<iframe 
  src="/calculator/index.html" 
  style="width: 100%; min-height: 850px; border: none; border-radius: 16px;" 
  title="מחשבון מיצוי זכויות בן לולו סיבוני">
</iframe>
```

### אפשרות 3: העלאה כמערכת עצמאית / סאב-דומיין נפרד
ניתן להעלות את הקבצים ישירות לכל שרת או שירות אחסון חינמי/קל:
* **Vercel / Netlify / Cloudflare Pages / GitHub Pages**: פשוט גוררים את התיקייה ומקבלים כתובת פעילה תוך 10 שניות (למשל: `rights.blslaw.co.il`).

## 🔐 כניסה לעמוד הניהול (`bhvuk.html`)

עמוד הניהול מאפשר למשרד לצפות בכל הפניות (הן בדיקות שהושלמו עד הסוף והן לידים שננטשו באמצע אך השאירו טלפון):
* **קישור:** פותחים את `bhvuk.html` בדפדפן (או לוחצים על "מערכת ניהול פניות" בפוטר של השאלון).
* **סיסמת כניסה מוגדרת:** `blslaw2026` (תומך גם ב-`ghtlaw2020`).
* **מה המערכת מאפשרת?**
  1. צפייה בפרטי הפונה, מספר הטלפון, עילת הפגיעה ומקור ההגעה (Google Ads, Facebook, אורגני).
  2. חיוג ישיר בלחיצה אחת או פתיחת שיחת וואטסאפ מנוסחת מראש.
  3. עדכון סטטוס טיפול (חדש / בטיפול / תואמה פגישה / נסגר).
  4. כתיבת הערות פנימיות שנשמרות אוטומטית.
  5. ייצוא מלא של כל הנתונים לקובץ אקסל / CSV בלחיצת כפתור אחת.

## 📩 קבלת התראות למייל / חיבור ל-CRM (Webhook)

אם תרצו שכל ליד חדש ישלח מיד התראה למייל (`office@blslaw.co.il`) או למערכת CRM / Make / Zapier:
בתוך הקובץ `data.js` בשורה האחרונה (או בראש הקובץ), מגדירים את כתובת הוובהוק:
```javascript
window.BLS_FIRM_CONFIG.webhookUrl = 'https://hook.eu2.make.com/YOUR_WEBHOOK_URL';
```
ברגע שמגדירים כתובת זו, המערכת שולחת באופן אוטומטי JSON מלא עם כל פרטי הפונה, התשובות ואפיקי הזכויות בכל פעם שמתקבל ליד!
